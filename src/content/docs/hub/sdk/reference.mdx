## Client

Client classes for interacting with the Giskard Hub API. Two flavours are available with an identical API surface — pick the one that matches your runtime.

<Tabs>
  <TabItem label="Sync">
```python
from giskard_hub import HubClient

hub = HubClient()
projects = hub.projects.list()

````
  </TabItem>
  <TabItem label="Async">
```python
from giskard_hub import AsyncHubClient
import asyncio


async def main():
    async with AsyncHubClient() as hub:
        projects = await hub.projects.list()


asyncio.run(main())
````

  </TabItem>
</Tabs>

:::tip
All methods documented below are shown in their synchronous form. The async variants are identical -- just `await` them.
:::

### `HubClient`

Synchronous client. All resource operations are available as attributes.

```python title="Constructor"
from giskard_hub import HubClient

hub = HubClient(
    api_key="gsk_...",                  # or set GISKARD_HUB_API_KEY env var
    base_url="https://hub.example.com", # or set GISKARD_HUB_BASE_URL env var
)
```

<Property
  name="api_key"
  type="str | None"
  defaultValue="env GISKARD_HUB_API_KEY"
>
  Your Hub API key.
</Property>
<Property
  name="base_url"
  type="str | httpx.URL | None"
  defaultValue="env GISKARD_HUB_BASE_URL"
>
  Base URL of your Hub instance.
</Property>
<Property
  name="tenant_host"
  type="str | None"
  defaultValue="env GISKARD_HUB_TENANT_HOST"
>
  Hub tenant hostname. When set, the SDK attaches it as `X-Forwarded-Host` on
  every request. Only needed when `base_url`'s host isn't the tenant host (e.g.
  internal Docker networking).
</Property>
<Property name="auto_add_api_suffix" type="bool" defaultValue="True">
  Automatically append `/_api` to `base_url`.
</Property>
<Property
  name="timeout"
  type="float | httpx.Timeout | None"
  defaultValue="60.0"
>
  Default request timeout in seconds. Pass an `httpx.Timeout` for fine-grained
  control over connect, read, and write timeouts.
</Property>
<Property name="max_retries" type="int" defaultValue="2">

  responses).
</Property>
<Property

</Property>
<Property
  name="default_query"
  type="dict[str, object] | None"
  defaultValue="None"

</Property>
<Property name="http_client" type="httpx.Client | None" defaultValue="None">
  Custom `httpx.Client` instance for proxies, custom transports, or mutual TLS.
</Property>

### `hub.agents`

<ResourceSection description="Register, test, and invoke LLM agents. An agent represents your LLM application -- either a remote HTTP endpoint or a local Python callable.">

```python
from giskard_hub.types import (
    Agent,
    AgentOutput,
    ChatMessage,
    GenerateCompletionOutput,
)
```

<MethodCard name=".create()" returnType="Agent">
  Create a new agent with configuration for external API communication.

  <Property name="name" type="str" required>
    Display name of the agent.
  </Property>
  <Property name="url" type="str" required>
    HTTP endpoint the Hub calls during evaluations and scans.
  </Property>
  <Property name="project_id" type="str" required>
    Project this agent belongs to.
  </Property>
  <Property name="supported_languages" type="list[str]" required>
    Language codes the agent supports (e.g. `["en", "fr"]`).
  </Property>
  <Property name="headers" type="dict[str, str]">
    HTTP headers sent with every request to the agent (e.g. auth tokens), as a `{name: value}` dict.
  </Property>
  <Property name="description" type="str | None">
    Human-readable description.
  </Property>
  <Property name="input_schema" type="dict[str, Any] | None">
    JSON Schema describing the agent's expected input. Defaults to the conversational (chat) schema when omitted.
  </Property>
  <Property name="output_schema" type="dict[str, Any] | None">
    JSON Schema describing the agent's expected output. Defaults to the conversational (chat) schema when omitted.
  </Property>
  <Property name="auto_bindings" type="list[ForwardBindingParam | AggregateBindingParam] | None">
    Automatic input/output bindings. Chat agents get a default aggregate binding that rebuilds conversation history; pass `[]` for single-turn agents.
  </Property>

```python title="Example"
agent = hub.agents.create(
    project_id=project.id,
    name="Support Bot v2",
    url="https://my-app.example.com/api/chat",
    supported_languages=["en"],
    headers={"Authorization": "Bearer <token>"},
    description="GPT-4o chatbot with RAG",
)
```

</MethodCard>

<MethodCard name=".generate_completion()" returnType="GenerateCompletionOutput">
  Call a registered agent with a structured input and get the response.

  <Property name="agent_id" type="str" required>
    ID of the agent to call.
  </Property>
  <Property name="input" type="dict[str, Any]" required>

  <Property name="chat_id" type="str | None">

  </Property>
  <Property name="interactions" type="Iterable[tuple[dict, dict]] | None">

```python title="Example"
output = hub.agents.generate_completion(

print(output.output["response"]["content"])
print(output.output.get("metadata"))
```

</MethodCard>

<MethodCard name=".create()" returnType="Check">

#### Check type params

The `params` field accepts one of these shapes (main params shown; see the [built-in checks guide](/hub/sdk/guides/datasets-and-checks#built-in-checks) for full detail):

| Type                    | `params` shape                                                                                                                              | Evaluation method |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| **Correctness (Hub)**   | `{"type": "hub_correctness", "reference": str}`                                                                                             | LLM judge         |
| **Conformity (Hub)**    | `{"type": "hub_conformity", "rules": list[str]}`                                                                                            | LLM judge         |
| **Groundedness (Hub)**  | `{"type": "hub_groundedness", "context": str}`                                                                                              | LLM judge         |
| **LLM judge**           | `{"type": "llm_judge", "prompt": str}`                                                                                                      | LLM judge         |
| **Conformity**          | `{"type": "conformity", "rule": str}`                                                                                                       | LLM judge         |
| **Groundedness**        | `{"type": "groundedness", "context": str \| list[str], "context_key": str}`                                                                 | LLM judge         |
| **Contradiction**       | `{"type": "contradiction", "context": str \| list[str]}`                                                                                    | LLM judge         |
| **Toxicity**            | `{"type": "toxicity", "categories": list[str]}`                                                                                             | LLM judge         |
| **Answer relevance**    | `{"type": "answer_relevance"}`                                                                                                              | LLM judge         |
| **Semantic similarity** | `{"type": "semantic_similarity", "reference_text": str, "threshold": float}`                                                                | Embedding         |
| **String matching**     | `{"type": "string_matching", "keyword": str, "case_sensitive": bool}`                                                                       | Rule-based        |
| **Regex matching**      | `{"type": "regex_matching", "pattern": str}`                                                                                                | Rule-based        |
| **Comparisons**         | `{"type": "equals" \| "not_equals" \| "greater_than" \| "greater_than_equals" \| "less_than" \| "less_than_equals", "expected_value": Any}` | Rule-based        |
| **Metadata (Hub)**      | `{"type": "hub_metadata", "json_path_rules": list[JsonPathRule]}`                                                                           | Rule-based        |
| **JSON valid**          | `{"type": "json_valid", "expected_schema": dict}`                                                                                           | Rule-based        |
| **Readability**         | `{"type": "readability", "metric": str, "min_score": float, "max_score": float}`                                                            | Rule-based        |

Each `JsonPathRule`: `{"json_path": str, "expected_value": str, "expected_value_type": "string" | "number" | "boolean"}`

Every check also accepts a target path parameter to point it at a specific field of a structured output: `text_key` for the Hub LLM checks, `metadata_key` for `hub_metadata`, and `target_key` for the rest.

</ResourceSection>

```python
from giskard_hub.types import Evaluation, Metric, CheckResult
```

<MethodCard name=".create()" returnType="Evaluation">
  Create and launch a new evaluation of an agent on a dataset.

<Property name="project_id" type="str" required>
  Project ID.
</Property>
<Property name="agent_id" type="str" required>
  Agent to evaluate.
</Property>
<Property name="dataset_id" type="str | None">
  Dataset to evaluate against. Provide this **or** `old_evaluation_id`, not

</Property>
<Property name="old_evaluation_id" type="str | None">

<Property name="name" type="str">

<Property name="tags" type="list[str] | None">

<Property name="run_count" type="int">

  Link to a scheduled evaluation.

<MethodCard name=".run_single()" returnType="list[CheckResult]">
  Evaluate a single (input, output) pair against checks without creating a full evaluation.

## Error types

All exceptions inherit from `HubClientError` and are importable from the root package.

```python
from giskard_hub import (
    HubClientError,  # Base exception for all SDK errors
    APIStatusError,  # Base for HTTP status errors (has .status_code, .response)
    APITimeoutError,  # Request timed out
    APIConnectionError,  # Could not connect to the Hub
    BadRequestError,  # 400
    AuthenticationError,  # 401 — invalid or missing API key
    PermissionDeniedError,  # 403 — insufficient permissions
    NotFoundError,  # 404 — resource does not exist
    ConflictError,  # 409 — resource conflict
    UnprocessableEntityError,  # 422 — validation error
    RateLimitError,  # 429 — too many requests
    InternalServerError,  # 500+ — server error
)
```

```python title="Error handling example"
from giskard_hub import HubClient, NotFoundError, AuthenticationError

hub = HubClient()

try:
    agent = hub.agents.retrieve("nonexistent-id")
except NotFoundError as e:
    print(f"Agent not found: {e}")
except AuthenticationError:
    print("Check your API key")
```

## Advanced patterns

### Pagination

Methods that support pagination accept `limit` and `offset`. Pass `include_metadata=True` to get an `APIPaginatedMetadata` object:

```python title="Pagination example"
results, metadata = hub.evaluations.results.search(
    "evaluation-id", limit=50, offset=0, include_metadata=True,
)
print(f"Page: {metadata.count} of {metadata.total} (offset {metadata.offset})")
```

### Raw response access

```python title="Access HTTP headers and status"
response = hub.with_raw_response.agents.retrieve("agent-id")
print(response.status_code)
agent = response.parse()
```

### Retries and timeouts

```python title="Per-request override"
hub.with_options(max_retries=5, timeout=300.0).evaluations.create(...)
```

### Custom HTTP client

```python title="Proxy configuration"
from giskard_hub import HubClient, DefaultHttpxClient

hub = HubClient(
    http_client=DefaultHttpxClient(proxy="http://proxy.example.com:8080"),
)
```

### Debug logging

```bash title="Enable debug logging"
export GISKARD_HUB_LOG=debug
```
