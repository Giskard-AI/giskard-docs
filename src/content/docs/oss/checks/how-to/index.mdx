Task-oriented guides for writing tests with Giskard Checks. These guides assume you're familiar with scenarios and checks; the terms used here are introduced in [Core Concepts](/oss/checks/explanation/core-concepts). Each guide focuses on getting a specific job done.

Start with [Run Tests with pytest](/oss/checks/how-to/run-in-pytest) — it opens with a test you can run before configuring any provider — and finish with [CI/CD Integration](/oss/checks/how-to/ci-cd). The guides are ordered so the ones that need no LLM API key come first; the last three call a provider and are marked below.

For two self-contained scripts you can run straight from a checkout, see [`examples/`](https://github.com/Giskard-AI/giskard-oss/tree/main/examples) in the `giskard-oss` repository. `examples/checks_static/test_checks_static.py` is a passing test in fifteen lines and needs no API key.
