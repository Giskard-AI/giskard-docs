Configuration reference for Giskard Checks: the default LLM model behind LLM
checks, the embedding model used by semantic checks, and how much of a suite
report gets printed.

Two models are configured here. The generator is the LLM the library calls; when
a check uses it to decide whether an answer is acceptable, that role is called
the judge. The embedding model turns text into vectors so checks like
`SemanticSimilarity` can compare meaning rather than exact wording. Both default
to OpenAI models and both send your test inputs and agent outputs to the
provider you configure.

---

## Settings

**Module:** `giskard.checks.settings`

### `GiskardChecksSettings`

A Pydantic `BaseSettings` model holding the environment-backed configuration.
Every field can be set through an environment variable prefixed with
`GISKARD_CHECKS_`, or through a `.env` file at the project root. Unknown
variables are ignored.

<Property name="default_model" type="str" defaultValue='"openai/gpt-4o-mini"'>Default LLM model identifier used by checks that are constructed without an explicit generator. Environment variable: `GISKARD_CHECKS_DEFAULT_MODEL`.</Property>
<Property name="default_embedding_model" type="str" defaultValue='"text-embedding-3-small"'>Default embedding model identifier used by checks that are constructed without an explicit model, such as `SemanticSimilarity`. Environment variable: `GISKARD_CHECKS_DEFAULT_EMBEDDING_MODEL`.</Property>
<Property name="disable_rich_pretty" type="bool" defaultValue="False">Skip installing `rich.pretty` on import. Importing `giskard.checks` normally installs rich's pretty printer for nicer REPL output; set this to disable it. Environment variable: `GISKARD_CHECKS_DISABLE_RICH_PRETTY`.</Property>
<Property name="max_reported_failures" type="int | None" defaultValue="None">Maximum number of failures included in suite reports. `None` means unlimited. Values that cannot be parsed as a non-negative integer fall back to `None`. Environment variable: `GISKARD_CHECKS_MAX_REPORTED_FAILURES`.</Property>

```bash
# .env
GISKARD_CHECKS_DEFAULT_MODEL=openai/gpt-5-mini
GISKARD_CHECKS_DEFAULT_EMBEDDING_MODEL=text-embedding-3-large
GISKARD_CHECKS_MAX_REPORTED_FAILURES=20
GISKARD_CHECKS_DISABLE_RICH_PRETTY=true
```

<MethodCard name="get_settings()" returnType="GiskardChecksSettings">
  Return the settings loaded from the environment. A fresh instance is built on
  every call, so changes to environment variables are picked up without
  restarting the process.
</MethodCard>

```python
from giskard.checks import get_settings

settings = get_settings()
print(settings.default_model)  # "openai/gpt-4o-mini"
```

:::note
`disable_rich_pretty` is read once, when `giskard.checks` is first imported.
Set it in the environment or `.env` before the import for it to take effect.
:::

## Default generator

LLM-backed checks such as `LLMJudge`, `Groundedness` and `Toxicity` use the
default generator when you do not pass one explicitly. A runtime override set
with `set_default_generator` takes precedence over
`GISKARD_CHECKS_DEFAULT_MODEL`.

Point this at a capable model. A weak model produces unreliable verdicts in both
directions: tests pass on answers that should fail, and fail on answers that were
correct. For a bank support agent, a weak judge will wave through a reply that
quietly gives investment advice the agent was supposed to refuse. That shows up
as flaky tests, not as an error, so read the failing verdicts before you trust
them, and treat a suite that passes as evidence rather than proof.

<MethodCard name="set_default_generator()" returnType="None">
  Set the default LLM generator for all checks. The override is process-global.

  <Property name="generator" type="BaseGenerator" required>The generator to use as the default for all LLM checks.</Property>
</MethodCard>

<MethodCard name="get_default_generator()" returnType="BaseGenerator">
  Return the current default generator: the runtime override if one was set,
  otherwise a `Generator` built from `GISKARD_CHECKS_DEFAULT_MODEL` (falling
  back to `openai/gpt-4o-mini`).
</MethodCard>

```python
from giskard.agents.generators import Generator
from giskard.checks import get_default_generator, set_default_generator

set_default_generator(Generator(model="openai/gpt-5-mini"))

get_default_generator()  # the generator set above
```

:::tip[Configuring pytest runs]
Set the generator once per session in a `conftest.py` fixture rather than in
every test module. See [CI/CD Integration](/oss/checks/how-to/ci-cd).
:::

<MethodCard name="get_default_embedding_model()" returnType="EmbeddingModel">
  Return an `EmbeddingModel` built from `GISKARD_CHECKS_DEFAULT_EMBEDDING_MODEL`
  (falling back to `text-embedding-3-small`). Importable from
  `giskard.checks.settings`.
</MethodCard>

## Imports

`set_default_generator` and `get_default_generator` are part of the public
`giskard.checks` API. `get_settings` is importable from the same package, but
it is not listed in `__all__`:

```python
from giskard.checks import (
    get_default_generator,
    get_settings,
    set_default_generator,
)
```

`GiskardChecksSettings` and `get_default_embedding_model` live in the settings
module:

```python
from giskard.checks.settings import (
    GiskardChecksSettings,
    get_default_embedding_model,
)
```
