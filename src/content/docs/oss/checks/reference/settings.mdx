Environment and runtime configuration for Giskard Checks: generator, judge, and embedding defaults. How they differ in practice is summarized in [Generators and judges](/oss/checks/explanation/core-concepts#generators-and-judges).

**Module:** `giskard.checks.settings`

---

## `GiskardChecksSettings`

Pydantic `BaseSettings` model. Every field can be set with an environment variable prefixed `GISKARD_CHECKS_`, or in a `.env` file at the project root. Unknown variables are ignored.

<Property name="default_model" type="str" defaultValue='"openai/gpt-4o-mini"'>
  Default model identifier for content generation and for judges that do not have
  a separate default. Used by `get_default_generator()` when no runtime override
  is set, and by the fallback `LLMChatJudge()` from `get_default_judge()` when
  neither a runtime judge nor `default_judge` is configured. Environment
  variable: `GISKARD_CHECKS_DEFAULT_MODEL`.
</Property>
<Property name="default_judge" type="str | None" defaultValue="None">
  Optional default judge: a provider/model string (optional `llm/` or `som/` kind
  prefix), or a JSON object parsed by `BaseJudge.parse`. When unset, judges fall
  back to an `LLMChatJudge` that tracks the default generator. Environment
  variable: `GISKARD_CHECKS_DEFAULT_JUDGE`.
</Property>
<Property
  name="default_embedding_model"
  type="str"
  defaultValue='"text-embedding-3-small"'
>
  Embedding model used by checks constructed without an explicit model.
  Environment variable: `GISKARD_CHECKS_DEFAULT_EMBEDDING_MODEL`.
</Property>
<Property name="disable_rich_pretty" type="bool" defaultValue="False">
  When `False` (the default), importing `giskard.checks` installs `rich.pretty`
  for nicer REPL output. Environment variable:
  `GISKARD_CHECKS_DISABLE_RICH_PRETTY`.
</Property>
<Property name="max_reported_failures" type="int | None" defaultValue="None">
  How many failed or errored scenarios the printed suite report includes. `None`
  means all of them. The `SuiteResult` object still holds every scenario; this
  only truncates the Rich output. Values that are not a non-negative integer
  become `None`. Environment variable: `GISKARD_CHECKS_MAX_REPORTED_FAILURES`.
</Property>

```bash
# .env
GISKARD_CHECKS_DEFAULT_MODEL=openai/gpt-5-mini
GISKARD_CHECKS_DEFAULT_JUDGE=openai/gpt-5
GISKARD_CHECKS_DEFAULT_EMBEDDING_MODEL=text-embedding-3-large
GISKARD_CHECKS_MAX_REPORTED_FAILURES=20
GISKARD_CHECKS_DISABLE_RICH_PRETTY=true
```

<MethodCard name="get_settings()" returnType="GiskardChecksSettings">
  Return a new `GiskardChecksSettings` loaded from the environment. Each call
  rebuilds the object, so changes to environment variables are picked up without
  restarting the process.
</MethodCard>

```python
from giskard.checks.settings import get_settings

settings = get_settings()
print(settings.default_model)  # "openai/gpt-4o-mini"
```

:::note
`disable_rich_pretty` is read once, when `giskard.checks` is first imported.
Set it in the environment or `.env` before that import.
:::

## Default generator

`UserSimulator`, `LLMGenerator`, and other content-generation paths use this generator when you do not pass one yourself. A runtime override from `set_default_generator` wins over `GISKARD_CHECKS_DEFAULT_MODEL`. LLM checks use [Generators and judges](/oss/checks/explanation/core-concepts#generators-and-judges) — verdicts go through `get_default_judge()`, not this default.

<MethodCard name="set_default_generator()" returnType="None">
  Set the default model for content generation.

  <Property name="generator" type="BaseGenerator | str" required>A generator instance, or a model identifier string (e.g. `"openai/gpt-4o-mini"`) wrapped in `Generator` automatically.</Property>
</MethodCard>

<MethodCard name="get_default_generator()" returnType="BaseGenerator">
  Return the runtime override if one was set, otherwise a `Generator` built from
  `GISKARD_CHECKS_DEFAULT_MODEL` (falling back to `openai/gpt-4o-mini`).
</MethodCard>

```python
from giskard.checks import get_default_generator, set_default_generator

set_default_generator("openai/gpt-5-mini")

get_default_generator()  # the generator set above
```

To set this once per pytest session, see [CI/CD Integration](/oss/checks/how-to/ci-cd).

## Default judge

LLM-backed checks such as `LLMJudge`, `Groundedness`, and `Toxicity` use `_judge`, which returns `judge` when set or otherwise `get_default_judge()`.

Resolution order for `get_default_judge()`:

1. Runtime override from `set_default_judge`
2. `GISKARD_CHECKS_DEFAULT_JUDGE` / `GiskardChecksSettings.default_judge` when set
3. `LLMChatJudge()` — its generator tracks `get_default_generator()`

<MethodCard name="set_default_judge()" returnType="None">
  Set the default judge independently of content generation.

  <Property name="judge" type="JudgeInput | None" required>
    A `BaseJudge`, `BaseGenerator`, or `BaseSOM` instance; a model identifier
    string (wrapped in `LLMChatJudge` or `SOMJudge` as appropriate); a JSON dict
    for `BaseJudge.parse`; or `None` to clear the runtime override.
  </Property>
</MethodCard>

<MethodCard name="get_default_judge()" returnType="BaseJudge">
  Return the configured judge using the resolution order above.
</MethodCard>

## Default embedding model

Checks such as `SemanticSimilarity` use this embedding model when you do not pass `embedding_model=` yourself. A runtime override from `set_default_embedding_model` wins over `GISKARD_CHECKS_DEFAULT_EMBEDDING_MODEL`.

## Configuring a custom provider endpoint

`giskard.llm.configure(name, provider=None, **kwargs)` registers a named provider configuration so you can reference it as a `"<name>/model"` model string anywhere a model id is accepted (`set_default_generator`, `set_default_judge`, a `Generator(...)` or `LLMChatJudge(...)` constructor, etc.). The provider is created lazily on first use and cached. Use it for OpenAI-compatible servers (vLLM, Ollama, OpenRouter, a Vertex AI OpenAPI endpoint, an internal gateway) that are not covered by the built-in provider prefixes.

`provider` selects the SDK to drive (default: the `name`). For an OpenAI-compatible endpoint use `provider="openai"`. `**kwargs` are forwarded to that provider's constructor. The `openai` provider accepts `api_key`, `base_url`, `timeout`, `http_client`, and `default_headers` (extra headers merged into every request). Values may use the `os.environ/VAR_NAME` form for deferred environment-variable resolution, so secrets are read at call time rather than at import.

```python
import giskard.llm
from giskard.checks import set_default_generator

giskard.llm.configure(
    "my-endpoint",
    provider="openai",
    base_url="https://my-llm-host.example.com/v1",
    api_key="os.environ/MY_ENDPOINT_API_KEY",
)

set_default_generator("my-endpoint/my-model-id")
```

For an OpenAI-compatible endpoint that authenticates with a request header rather than the `Authorization` header the SDK sends by default — for example Vertex AI's OpenAPI endpoint, which expects `x-goog-api-key` — pass `default_headers`. Set `api_key` to a non-empty placeholder (the SDK still requires it) and clear `Authorization` so the real key is sent only in your header:

```python
import giskard.llm
from giskard.agents.generators import Generator
from giskard.checks import set_default_generator

giskard.llm.configure(
    "vertex",
    provider="openai",
    api_key="dummy-key",
    base_url=(
        "https://aiplatform.googleapis.com/v1/projects/PROJECT"
        "/locations/global/endpoints/openapi"
    ),
    default_headers={"x-goog-api-key": "os.environ/VERTEX_API_KEY", "Authorization": ""},
)

set_default_generator(Generator(model="vertex/gemini-2.5-flash"))
```

`configure()` is a process-wide setting on the default `giskard.llm` client; call it once at startup (for example in a pytest `session` fixture or your conftest). `giskard.llm.reset()` clears registered providers, useful in tests.
