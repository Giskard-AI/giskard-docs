## `TestCase`

**Module:** `giskard.checks.core.testcase`

Bundle a trace with a set of checks to execute. Useful for testing against fixed interaction sequences or replaying recorded conversations.

:::note
For most use cases, use the `Scenario()` fluent API instead. `TestCase` is for advanced use cases where you need direct control over trace construction.
:::

<TypeTable name="TestCase">
  <Property name="name" type="str | None">
    Optional label for the test case.
  </Property>
  <Property name="trace" type="Trace" required>
    The trace containing interactions to test against.
  </Property>
  <Property name="checks" type="Sequence[Check]" required>
    Sequence of checks to run against the trace.
  </Property>
</TypeTable>

<MethodCard name=".run()" returnType="TestCaseResult">
  Execute all checks against the trace.

  <Property name="return_exception" type="bool" defaultValue="False">If True, return results even when exceptions occur instead of raising.</Property>
</MethodCard>

<MethodCard name=".assert_passed()" returnType="None">
  Run the test case and assert that all checks passed. Raises `AssertionError`
  with formatted failure messages if any check fails.
</MethodCard>

Examples on this page test BotaniBot, an assistant for a garden centre.

A conversation you captured in production, replayed against checks without calling the agent again:

```python
from giskard.checks import TestCase, Trace, Interaction, Equals

trace = Trace(
    interactions=[
        Interaction(
            inputs="Do you stock Monstera deliciosa?",
            outputs={"availability": "in_stock", "price_eur": 24.99},
        ),
        Interaction(
            inputs="And in a bigger pot?",
            outputs={"availability": "available_to_order", "price_eur": 39.99},
        ),
    ]
)

test_case = TestCase(
    name="monstera_stock_replay",
    trace=trace,
    checks=[
        Equals(expected_value="Hi there!", target_key="trace.interactions[0].outputs"),
        Equals(
            expected_value="I'm doing well!",
            target_key="trace.interactions[1].outputs",
        ),
    ],
)

result = await test_case.run()
```

### Integration with pytest

`assert_passed()` raises `AssertionError` with the check messages, so a failing check reads like any other pytest failure:

```python
import pytest

from giskard.checks import FnCheck, Interaction, TestCase, Trace


@pytest.mark.asyncio
async def test_vague_question_gets_a_follow_up():
    trace = Trace(
        interactions=[
            Interaction(
                inputs="My plant looks sad.",
                outputs="Sorry to hear that. Are the leaves yellow or drooping?",
            )
        ]
    )
    test_case = TestCase(
        name="asks_a_follow_up",
        trace=trace,
        checks=[
            FnCheck(
                fn=lambda t: "?" in t.last.outputs,
                name="asks_a_follow_up",
            ),
        ],
    )
    await test_case.assert_passed()
```

## `TestCaseResult`

**Module:** `giskard.checks.core.result`

Result of test case execution with check outcomes.

<TypeTable name="TestCaseResult">
  <Property name="status" type="TestCaseStatus">
    Overall test case status (PASS/FAIL/ERROR/SKIP).
  </Property>
  <Property name="results" type="list[CheckResult]">
    Results from all checks.
  </Property>
  <Property name="passed" type="bool">
    True if all checks passed.
  </Property>
  <Property name="failed" type="bool">
    True if any check failed.
  </Property>
  <Property name="errored" type="bool">
    True if any check errored.
  </Property>
  <Property name="skipped" type="bool">
    True if all checks were skipped.
  </Property>
  <Property name="duration_ms" type="int">
    Execution time in milliseconds.
  </Property>
</TypeTable>

<MethodCard name=".assert_passed()" returnType="None">
  Raise `AssertionError` with formatted failure messages if any check did not pass. Useful in pytest.
</MethodCard>

```python
result = await test_case.run()

if result.passed:
    print("All checks passed!")
else:
    for check_result in result.results:
        if check_result.failed:
            print(f"Failed: {check_result.message}")

# Assert (raises if failed)
result.assert_passed()
```

## `WithSpy`

**Module:** `giskard.checks.testing.spy`

Replace a function with a `MagicMock` while the wrapped interaction spec runs, then record what it was called with. Use it to assert that your agent passed the right arguments to an internal call.

<TypeTable name="WithSpy">
  <Property name="interaction_generator" type="InteractionSpec" required>
    The interaction spec to spy on.
  </Property>
  <Property name="target" type="str" required>
    Python import path of the function to patch, exactly as you would pass it to `unittest.mock.patch` (for example `"myapp.db.fetch_orders"`). This is not a JSONPath -- a trace expression such as `"trace.last.outputs"` raises.
  </Property>
</TypeTable>

After each interaction, the mock's call history is written to `Interaction.metadata` under the `target` string, then the mock is reset. The recorded keys are `call_count`, `call_args`, `call_args_list`, and `mock_calls`.

Assert that BotaniBot looked the order up rather than inventing a delivery date:

```python
from giskard.checks import Scenario, Interact, WithSpy

from botanibot.agent import order_support_agent

interaction_spec = Interact(
    inputs="Where is my order GC-40912?",
    outputs=order_support_agent,
)

spied_spec = WithSpy(
    interaction_generator=interaction_spec,
    target="botanibot.db.fetch_orders",  # Python import path -- same as mock.patch
)

result = await Scenario("order_lookup_hits_the_db").add_interaction(spied_spec).run()

# Spy data is keyed by the same import path
spy_data = result.final_trace.last.metadata.get("botanibot.db.fetch_orders")
print(spy_data["call_count"], spy_data["call_args"])
```

:::tip
Use `WithSpy` when debugging complex interaction generation logic, understanding multi-turn interaction flow, or investigating unexpected behavior in scenarios.
:::

## Usage patterns

### Replaying recorded conversations

A support transcript, replayed to confirm the advice you shipped is still the advice the checks expect:

```python
from giskard.checks import TestCase, Trace, Interaction, FnCheck

recorded = [
    Interaction(
        inputs="The leaves on my Monstera are turning yellow.",
        outputs="Yellow leaves usually mean overwatering. Let the soil dry out first.",
    ),
    Interaction(
        inputs="Should I add fertiliser?",
        outputs="Not while it is stressed. Wait until new growth appears.",
    ),
]

trace = Trace(interactions=recorded)

test_case = TestCase(
    name="yellow_leaves_replay",
    trace=trace,
    checks=[
        FnCheck(
            fn=lambda t: "overwatering" in t.interactions[0].outputs.lower(),
            name="names_the_likely_cause",
        ),
        FnCheck(
            fn=lambda t: "wait" in t.interactions[1].outputs.lower(),
            name="does_not_recommend_feeding",
        ),
    ],
)

await test_case.assert_passed()
```

Replay is free and deterministic: no agent runs, so a failure means the checks disagree with a reply you already have.

### Batch testing

Run independent test cases concurrently:

```python
import asyncio

test_cases = [
    TestCase(
        name=f"replay_{i}",
        trace=Trace(interactions=[interaction]),
        checks=[
            FnCheck(fn=lambda t: bool(t.last.outputs), name="answered")
        ],
    )
    for i, interaction in enumerate(recorded)
]

results = await asyncio.gather(*[tc.run() for tc in test_cases])

passed = sum(1 for r in results if r.passed)
print(f"Passed: {passed}/{len(results)}")
```

### Parameterized tests

One check, many recorded exchanges:

```python
import pytest

from giskard.checks import Interaction, StringMatching, TestCase, Trace


def botanibot(inputs: str) -> str:
    """Stand-in for the agent under test. Replace with your own call."""
    if "water" in inputs.lower():
        return "Let the top 2 cm of soil dry out before watering again."
    return "Ferns want bright, indirect light and no midday sun."


test_data = [
    ("How often should I water a Monstera?", "soil"),
    ("How much light does a fern need?", "light"),
]


@pytest.mark.asyncio
@pytest.mark.parametrize("question,required_keyword", test_data)
async def test_care_answers_mention_the_condition(question, required_keyword):
    trace = Trace(
        interactions=[Interaction(inputs=question, outputs=botanibot(question))]
    )
    test_case = TestCase(
        name=f"care_answer_{required_keyword}",
        trace=trace,
        checks=[
            Equals(expected_value=expected_output, target_key="trace.last.outputs")
        ],
    )
    await test_case.assert_passed()
```
