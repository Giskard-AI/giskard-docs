A scan writes test cases for your agent, runs them, and reports which ones it failed. You do not need prior experience with LLM evaluation or red teaming to follow these walkthroughs. Work through them with a Python file open. Each one ends with something you can run again.

Start with **Your First Scan**, which runs a vulnerability scan against a small garden-center assistant, walks through the report, and saves the generated suite so you can replay it. **Scan a RAG Agent** goes next if your agent answers from documents: it builds a knowledge base and runs a quality scan that looks for hallucination, out-of-scope answers, and sycophancy. **Write a Custom Scenario Generator** is the last step, for risks specific to your domain that the built-in generators do not cover.
